## Colors
- Primary: Deep Luxury Maroon `345 100% 18%` (#5B0017)
- Secondary: Cream `30 14% 92%`
- Accent/Gold: `43 72% 52%` (#D4AF37) — icons, active tabs, ratings, highlights
- Background: Soft Cream `30 14% 96%` (#F8F5F2)
- Card: Near-white `30 20% 99%`
- Matte Black: `0 0% 7%` (#121212) — nav bars, footer, sidebar

## Typography
- Headings: Playfair Display (serif, elegant)
- Body: Inter (clean, modern)

## Effects
- `glass` / `glass-dark` — glassmorphism with blur + saturation
- `shadow-luxury` — double-layered premium shadow
- `shadow-maroon` / `shadow-gold` — colored glow shadows
- `gradient-maroon` — primary gradient for buttons, hero overlays
- `gradient-dark` — matte black gradient for footer/nav
- `btn-glow` — gold inset glow on hover + scale-down on press
- `vip-border` — gold border + glow for VIP/promo elements
- `luxury-pulse` — premium loading animation

## Guidelines
- Stars/ratings use gold color
- Restaurant names use primary (maroon) color
- Bottom nav uses gold for active state, glass-dark background
- Footer uses gradient-dark with gold headings and light text
- Buttons use gradient-maroon with btn-glow effect
